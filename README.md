# LingoExtractor (영어 EPUB/TXT/PDF 중고급 어휘 추출기) 📚✨

LingoExtractor는 100% 서버리스 구조로 설계된 **순수 클라이언트 정적 단일 페이지 어플리케이션(SPA)**입니다.
영어 전자책(EPUB), 일반 텍스트(TXT), PDF 문서 및 직접 복사한 본문에서 **학습자 맞춤형 중고급(CEFR 레벨 B1 이상) 단어를 스마트하게 추출**하고, 지명·인명·고유명사와 너무 쉬운 초급 단어(A1~A2)는 배제하여 개인 Anki/CSV 단어장을 즉석에서 생성해 줍니다.

모든 자연어 처리와 파일 압축 해제, 텍스트 파싱 연산이 사용자의 브라우저 내에서만 100% 동작하므로, **CORS 보안 차단 문제나 파일 쓰기 제한, 서버리스 타임아웃 제한(10초)이 원천적으로 존재하지 않습니다.**
또한, **GitHub Pages 등을 통해 영구 무상 배포 및 가동이 가능**합니다.

> [!NOTE]
> 사용자의 요청에 따라 불필요한 번역 API 호출 및 의존성을 모두 걷어내고, **순수 어휘 학습과 원서의 문맥(Context) 파악에만 온전히 집중**할 수 있도록 콤팩트하게 다이어트되었습니다.

## 🎨 독보적인 UI/UX 및 디자인 미학 (Premium Aesthetics)

LingoExtractor는 기능뿐만 아니라 사용자를 매료시키는 세련된 글래스모피즘 디자인 시스템을 갖추고 있습니다.

*   **기본 라이트 글래스모피즘 테마 (Default Light Mode)**: 화사한 화이트 실버 톤의 반투명 디자인과 은은한 미러링 반사 테두리를 통해 극대화된 가독성을 제공합니다.
*   **다크 Slate 테마 지원 (Interactive Dark Mode)**: 우측 상단 테마 아이콘을 누르면, 눈의 피로를 지워주는 현대적인 딥 네이비/차콜 베이스 그라데이션 Slate 모드로 유려하게 실시간 트랜지션 스왑됩니다.
*   **FHD 해상도 최적화 및 동적 레이아웃 스왑 (Dynamic Width Swap)**:
    *   **분석 대기(초기 화면)**: 가로 `1120px` 콤팩트 그리드로 설계되어 FHD(1080p) 해상도 모니터에서도 화면 스크롤바가 생기지 않고 한눈에 쏙 들어옵니다.
    *   **분석 완료(결과 화면)**: 분석이 완료되는 즉시, 가로폭이 부드러운 애니메이션과 함께 **`1400px` 와이드 대시보드로 자동 확장**되어 풍성한 단어장과 문맥 예문을 시원하게 표출합니다. [처음으로] 버튼 클릭 시 다시 `1120px` 너비로 우아하게 오므라듭니다.
*   **동적 듀얼 통계 분석 차트 (Interactive 2-Way Chart)**:
    *   차트 우측 상단의 글래스 스위치 버튼을 통해 **`CEFR 레벨별 어휘 분포`** 및 **`품사별 어휘 분포(9대 품사)`** 도넛 그래프를 실시간으로 유연하게 토글 교체합니다.
    *   차트 세그먼트 마우스 오버 시 절대 개수와 함께 **전체 대비 점유 비중(%)을 즉석 수학 연산**하여 이쁘게 띄워주는 고도화된 툴팁 팝업을 제공합니다.
*   **다단 미세 어휘 필터 그리드**: 한글로 완전 치환된 직관적이고 다채로운 9대 품사 토글 배지 그리드, 이중 범위 정밀 빈도수 슬라이더, 단어 글자 수(길이) 수학적 부등식 필터가 리액티브하게 동기화 동작합니다.

## 🚀 독보적인 클라이언트 엔진 (Client-Side NLP & Parser Engine)

1.  **브라우저 단 파일 파싱 (JSZip & PDF.js)**:
    *   **EPUB**: Zip 압축 포맷인 EPUB의 `container.xml` 및 `content.opf`를 브라우저 내에서 직접 XML 구조화 분석하여 **실제 독서 Spine Order에 맞춰 텍스트를 정렬 및 파싱**합니다.
    *   **PDF**: PDF.js CDN을 내장하여 PDF 문서 내부 텍스트 레이어를 고속으로 결합 추출합니다.
    *   **TXT & 클립보드**: `FileReader`를 활용해 기호 깨짐 없이 텍스트를 인입하며, 원클릭 클립보드 붙여넣기를 지원합니다.
2.  **오프라인 하이브리드 POS / CEFR 룩업 엔진**:
    *   파이썬 `cefrpy`가 쓰던 17만 2,782개의 단어 난이도 사전을 `{ word: { pos: level } }` 구조로 오프라인 마이그레이션한 `cefr_db.json` 파일이 내장되어 있습니다.
    *   웹 페이지 최초 실행 시 단 1회 룩업용 JSON 파일을 fetch하여 메모리 해시맵에 캐싱하므로, **0초 만에 17만 단어를 룩업**하여 CEFR 등급과 사전 품사를 실시간 판별합니다.
3.  **지능형 굴절 복원 규칙 Lemmatizer & POS 예측기**:
    *   NLTK 자연어 처리 라이브러리를 브라우저에서 에뮬레이션하기 위해, 내장 불규칙 변화어 사전(명사/동사 150여 종) 및 복잡한 정규식 복원 규칙 기반 `lemmatize(word, pos)` 알고리즘을 완비했습니다.
    *   데이터베이스에 없는 신생/특수 단어의 경우, 단어 접미사(Suffix) 규칙 기반 품사 예측기(`guessPOS`)를 결합하여 높은 판정 정확도를 자랑합니다.
4.  **지능형 고유명사 & 인명/지명 필터링**:
    *   문장 내 첫 글자 대문자 일반 단어 복원 검사 및 CEFR DB 교차 검증을 통해, 책 속 등장인물(예: *Harry*, *Hermione*) 및 지명, 단체 등의 고유명사는 철저하게 걸러내고 실생활 영어 단어만 발췌합니다.
5.  **책 속 실제 문맥 예문 (Context Sentences)**:
    *   추출된 단어가 도서 내부에서 실제로 쓰인 생생한 첫 문장을 발췌 매칭해 주며, 단어 더블 클릭 시 모달 드로어가 열리며 하이라이트된 문장 상세 정보가 표시됩니다.

## 🛠️ 실행 및 배포 방법 (How to Deploy & Run)

### 1. GitHub Pages를 통한 무료 웹 배포 (추천)
1.  이 저장소를 **Fork** 하거나 새로운 GitHub 저장소를 만들어 소스 코드를 푸시합니다.
2.  저장소 설정(`Settings`) -> `Pages` 탭으로 이동합니다.
3.  **Build and deployment** 항목에서 Source를 `Deploy from a branch`로 설정하고 Branch를 `main` (또는 `master`) / `/root`로 선택한 후 `Save`를 누릅니다.
4.  잠시 후 부여되는 깃허브 Pages 고유 도메인(예: `https://[사용자ID].github.io/extractWords/`)으로 접속하면 즉각 세계 어디서나 무료로 프로그램이 구동됩니다!

### 2. 로컬에서 단순 실행
*   의존하는 웹 서버나 설치형 패키지가 전혀 없으므로, 로컬 환경에서 `index.html` 파일을 더블클릭하여 브라우저로 여는 것만으로도 즉시 실행 및 활용이 가능합니다!
*   (JSON 로컬 fetch 보안 문제를 피하기 위해 VSCode의 `Live Server` 확장 프로그램 등으로 실행하시는 것을 권장합니다.)
