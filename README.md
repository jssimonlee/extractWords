# LingoExtractor (영어 EPUB/TXT/PDF 중고급 어휘 추출기) 📚✨

영어 원서(EPUB), 일반 텍스트(TXT), PDF 문서 및 직접 복사한 영어 본문에서 **학습자 맞춤형 중고급(CEFR 레벨 B1 이상) 단어만 똑똑하게 추출**하고, 지명·인명·고유명사 및 너무 쉬운 초급 단어(A1~A2)는 완벽하게 배제하여 스마트한 Anki/CSV 단어장을 만들어주는 현대적이고 반응성이 풍부한 프리미엄 글래스모피즘 웹 어플리케이션입니다.

---

## 🎨 독보적인 UI/UX 및 디자인 미학 (Premium Aesthetics)

LingoExtractor는 단순한 기능성 툴을 넘어 사용자를 매료시키는 명품 디자인 시스템을 갖추고 있습니다.

*   **기본 라이트 글래스모피즘 테마 (Default Light Mode)**: 화사한 화이트 실버 톤의 반투명 디자인과 극대화된 가독성, 은은한 미러링 반사 테두리를 첫 화면에 조화롭게 제공합니다.
*   **다크 Slate 테마 지원 (Interactive Dark Mode)**: 우측 상단 테마 아이콘을 누르면, 눈의 피로를 지워주는 현대적인 딥 네이비/차콜 베이스 그라데이션 Slate 모드로 유려하게 실시간 트랜지션 스왑됩니다.
*   **FHD 해상도 최적화 및 동적 레이아웃 스왑 (Dynamic Width Swap)**:
    *   **분석 대기(초기 화면)**: 가로 `1120px` 콤팩트 그리드로 설계되어 FHD(1080p) 해상도 모니터에서도 화면 스크롤바가 생기지 않고 한눈에 쏙 들어옵니다.
    *   **분석 완료(결과 화면)**: 분석 텍스트 전송이 성공하는 즉시, 가로폭이 부드러운 애니메이션과 함께 **`1400px` 와이드 대시보드로 자동 확장**되어 풍성한 단어장과 문맥 예문을 시원하게 표출합니다. [처음으로] 버튼 클릭 시 다시 `1120px` 너비로 우아하게 오므라듭니다.
*   **동적 듀얼 통계 분석 차트 (Interactive 2-Way Chart)**:
    *   차트 우측 상단의 글래스 스위치 버튼을 통해 **`CEFR 레벨별 어휘 분포`** 및 **`품사별 어휘 분포(9대 품사)`** 도넛 그래프를 실시간으로 유연하게 토글 교체합니다.
    *   차트 세그먼트 마우스 오버 시 절대 개수와 함께 **전체 대비 점유 비중(%)을 즉석 수학 연산**하여 이쁘게 띄워주는 고도화된 툴팁 팝업을 제공합니다.
*   **다단 미세 어휘 필터 그리드**: 한글로 완전 치환된 직관적이고 다채로운 9대 품사 토글 배지 그리드, 이중 범위 정밀 빈도수 슬라이더, 단어 글자 수(길이) 수학적 부등식 필터가 리액티브하게 동기화 동작합니다.

## 🚀 독보적인 기능성 (Key Features)

1.  **다양한 입력 소스 완벽 지원 (EPUB + TXT + PDF + 클립보드 직접 분석)**:
    *   소장 중인 **영어 EPUB 전자책, 일반 TXT 문서, PDF 파일** 업로드를 지원하며, 복사해 둔 영어 뉴스를 원클릭으로 붙여넣어 즉석 파싱할 수 있는 **[클립보드 분석 & 텍스트 직접 입력]** 융합 컴포넌트를 탑재했습니다.
2.  **정밀한 9대 품사 분류 및 전치사/접속사 분해**:
    *   기존의 단순 품사 매핑을 혁신하여 **명사, 동사, 조동사, 형용사, 부사, 대명사, 전치사, 접속사, 기타**의 9대 품사 체계를 구현했습니다.
    *   NLTK 자연어 처리 태깅에서 같은 `IN`으로 분류되어 묶여 나오던 전치사와 접속사를 스펠링 교차 검증을 통해 **100% 접속사와 전치사로 해체 분리**해 내는 정교한 알고리즘을 장착했습니다.
3.  **지능형 고유명사 & 인명/지명 필터링**:
    *   `NLTK POS Tagging`과 문장 첫머리 일반 단어 변환 검사 알고리즘을 통해, 책 속 등장인물(예: *Harry*, *Hermione*) 및 지명, 단체 등의 고유명사는 엄격하게 제거하고 실생활 영어 단어만 발췌합니다.
4.  **부정 축약어 접두사 및 쓰레기 파편 제거**:
    *   단어 토크나이징 해체 결함으로 흘러나오는 축약 파편 단어들(`don`, `doesn`, `didn`, `'nt`, `'ll`, `'re`, `'ve` 등)을 전수 분석/포획하여 형태소 복원 수집 원형 단계에서 단 한 건의 유출도 없이 원천 배제합니다.
5.  **책 속 실제 문맥 예문 (Context Sentences)**:
    *   추출된 단어가 도서 내부에서 실제로 쓰인 생생한 첫 문장을 발췌 매칭해 주며, 단어 더블 클릭 시 모달 드로어가 열리며 하이라이트된 문장 상세 정보가 표시됩니다.
6.  **실시간 한국어 번역 & 영구 영리 캐싱**:
    *   무료 고성능 번역 API와 교차 연동하여 한국어 뜻을 매칭합니다. 한 번 번역된 어휘는 `translation_cache.json` 로컬 파일에 영구 캐싱 저장되어 다음번 호출부턴 0초 만에 분석 결과를 서빙합니다.
7.  **완벽한 Anki 단어장 생성 (TXT) 및 CSV 다운로드**:
    *   **Anki 내보내기**: 앞면에는 단어와 품사, 등급, 뒷면에는 한글 번역 뜻과 함께 **책 속 문맥 예문(핵심 타겟 어휘는 빨간색 볼드로 형광 강조)**이 HTML 스타일시트로 이식된 명품 Anki 전용 TXT 플랫 파일을 생성합니다.
    *   **CSV 내보내기**: 엑셀 등 스프레드시트에서 한글 인코딩이 전혀 깨지지 않도록 `UTF-8 BOM`이 정밀 주입된 깨끗한 데이터 파일을 제공합니다.

## 🛠️ 설치 및 실행 방법 (How to Run)

### 1. 사전 요구사항
*   **Python 3.10 이상** 권장

### 2. 필요한 라이브러리 의존성 설치
프로젝트 루트 디렉토리에서 터미널(PowerShell, CMD, Bash)을 열고 아래 명령어로 의존성 패키지를 원클릭 설치합니다:
```bash
pip install -r requirements.txt
```
> [!NOTE]
> 설치 과정에서 `pypdf`, `beautifulsoup4`, `cefrpy`, `nltk` 등 자연어 및 문서 파싱에 핵심적인 패키지들이 영구 마운트됩니다.

### 3. 프로그램 실행
서버 가동 명령어를 터미널에 입력합니다. 실행 시 필요한 NLTK 코퍼스 리소스(WordNet, Punkt 등)가 서버 내부에서 검사 후 자동 자가 진단 및 즉시 자동 다운로드 설치됩니다:
```bash
python app.py
```

### 4. 웹 어플리케이션 접속
브라우저를 열고 다음 주소에 접속하여 명품 웹 UI를 체험해 보세요!
*   👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 📂 파일 구조 명세 (File Structure)

*   `app.py`: Flask 웹 백엔드 서버 및 자연어 처리(NLP) 핵심 파이프라인 (EPUB/TXT/PDF 통합 파서, NLTK 자연어 분해기, cefrpy 등급 분류 및 고유명사 차단, MyMemory 번역 캐싱 서버).
*   `templates/index.html`: 반응형 프리미엄 글래스모피즘 UI 프론트엔드 (듀얼 탭 토글 차트, FHD 노스크롤 가변 레이아웃, 미세 필터링 그리드, Anki/CSV 익스포터 포함).
*   `requirements.txt`: 의존성 라이브러리 규격 목록.
*   `translation_cache.json` (자동 생성): 번역 API 호출 절약 및 성능 극대화를 위한 로컬 데이터베이스 캐시.
